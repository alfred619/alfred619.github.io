Lean Web Components: warm paper, 7 variables, no framework

I love web development because it’s immediate. You change a variable, you see the paper warm up.

This site is intentionally lean — warm paper #F5EECD for the blog, cool off-white #F7F8FA for the portfolio — 7 + 7 variables, no framework, no build step for the blog. Just HTML, CSS, and a little JS.

The 7 variables

:root{
  --paper:#f5f1e8;
  --surface:#fcfaf3;
  --ink:#1e1a13;
  --muted:#6b6151;
  --faint:#786d5b;
  --line:#e1d9c6;
  --accent:#b6491f;
}

That’s it. paper is the background you can feel, ink is the text you trust, accent is the one red that means “look here.” Light-only means I don’t maintain two worlds.

For the blog, the 7 are warmer: --blog-page:#F5EECD, --blog-text:#362C2C, --blog-accent:#ED680E — buttermilk, plum espresso, bold orange. Used via .blog-theme on body so the whole page flips warm.

Typography

Space Grotesk for UI and headlines — tight tracking, modern, friendly. Instrument Serif for editorial moments. JetBrains Mono for the small stuff: labels, dates, meta. All variable fonts, all system-fallback safe.

Constraint is a feature. 12 columns, one accent, two fonts. The rest is whitespace.

Components, not pages

Each work card is border:1px solid var(--border) + background:var(--surface) + border-radius:16px. No shadow until hover. The timeline is a grid: 11rem 1fr with a top border. The blog is just max-width:720px + line-height:1.75.

The stack is simple: static HTML, assets/styles.css, assets/main.js for the reveal observer. Blog posts are static HTML too — no markdown build step yet. When I need it, I’ll add Eleventy, but not before I need it. Properly means not adding what I don’t need.

View source, copy the 7 variables, make them yours. Change --accent to #0e7490 for a cooler paper, or --paper to #fffcf8 for warmer. The web is still the best place to build properly.
